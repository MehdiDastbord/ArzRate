ArzRate widget simplification

The home-screen widget was simplified to prioritize build stability:
- Removed SizeMode/LocalSize responsive sizing logic.
- Removed defaultWeight() usage.
- Removed widget clickable/action dependency.
- Removed TextUnit/legacy Sp handling.
- Uses only Glance dp/sp extensions for dimensions and text sizes.
- Keeps selected currencies, localized currency names, values, change indicators,
  and currency flag/symbol display.
- Widget automatically follows Android light/dark mode through ColorProvider.

The container used for this edit does not include the Android/Gradle toolchain,
so the APK could not be compiled locally here. GitHub Actions remains configured
for the debug build.
